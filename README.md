# avatar-core

Общий слой для работы с моделями видео-аватаров: единая «корзина» входов,
нормализация медиа и адаптеры провайдеров.

**Это единственная часть проекта, которая уедет на GitHub.** Всё, что касается
сравнения моделей — матрицы прогонов, отчёты, таблицы оценок — живёт в `..\lab\`,
снаружи этого репозитория, и публиковаться не должно.

## Что внутри

| Модуль | Зачем |
|---|---|
| `config.py` | секреты снаружи репозитория, настройки в yaml, подстановка `${VAR}` |
| `basket.py` | `Basket` — вход, одинаковый для всех моделей; `Asset` — файл с хешем и метаданными |
| `media.py` | ffmpeg: канон аудио, `share.mp4` под мессенджеры, превью, выбор формата кадра |
| `http.py` | ретраи, таймауты, маскировка ключей в логах |
| `providers/base.py` | контракт `AvatarProvider` и объявление возможностей |
| `providers/h3.py` | MiniMax H3 Fast Video (self-hosted) |
| `providers/kandinsky.py` | Kandinsky Avatars (`giga_avatar`) |

## Возможности провайдеров

| | Kandinsky | H3 |
|---|---|---|
| фото | ровно 1 (JPEG/PNG) | до 9 |
| аудио | ровно 1 (WAV **mono**) | до 3, каждое 2–15 с, сумма < 15 с |
| видео | нет | до 3, те же рамки |
| длительность | не задаётся | 4–15 с |
| формат кадра | не задаётся | 6 пресетов |
| seed | нет | есть |
| конкурентность | настраивается | **строго 1** — инстанс сериализует очередь |

Разный формат base64 (`data:` у H3, голый у Kandinsky) — забота адаптера,
общий слой об этом не знает.

## Секреты

Лежат в `%USERPROFILE%\.avatars\secrets.env`, шаблон — `.env.example`.
Путь переопределяется переменной `AVATARS_ENV_FILE`. В коде секреты читает
только `config.py`, в логи они не попадают — маскировка в `http.py`.

## Установка

```
pip install -e .
```

Отдельно нужен `ffmpeg` в PATH: `winget install Gyan.FFmpeg`
